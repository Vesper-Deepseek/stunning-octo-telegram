# Getting Started

## Install the MVP

Use the v1.0.4 universal APK from GitHub Releases:

https://github.com/Vesper-Deepseek/stunning-octo-telegram/releases/tag/v1.0.4

## Core workflow

1. Open Loose Ends.
2. Capture text, a screenshot, or voice.
3. Let the local extraction path prepare a draft.
4. Review the proposed person, direction, date, and other fields.
5. Edit anything that is wrong.
6. Confirm the draft to save it as a commitment.
7. Resolve or snooze commitments from the list views.

## Manual entry

Manual entry is available when you do not want to run extraction.

## No account required

The core local workflow is designed to work without an account.
